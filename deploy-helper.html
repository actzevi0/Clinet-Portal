🚀 EasyFinance – Deploy to Cloudflare Pages

פרסום ידני ישירות ל-Cloudflare Pages בלי Genspark

⚠️ הוראות: הרץ את הפקודות האלה בסדר מהמחשב שלך (Windows CMD / Mac Terminal)

שלב 1 — התקן Wrangler (פעם אחת בלבד)

npm install -g wrangler

שלב 2 — התחבר ל-Cloudflare

wrangler login

יפתח דפדפן → אשר → חזור ל-terminal

שלב 3 — צור תיקייה ריקה

mkdir easyfinance-deploy
cd easyfinance-deploy
mkdir admin css js

שלב 4 — הורד את כל הקבצים

הרץ את הפקודה הזו (PowerShell ב-Windows):

$base = "https://usekmdat.gensparkspace.com"
$files = @(
  "index.html",
  "dashboard.html",
  "admin/index.html",
  "admin/credentials.html",
  "admin/monthly-update.html",
  "admin/fix-data.html",
  "admin/check-data.html",
  "css/style.css"
)

# התחבר ל-Genspark קודם
$loginBody = @{username="admin";password="your-password"} | ConvertTo-Json
# הורד כל קובץ
foreach ($f in $files) {
  $url = "$base/$f"
  $out = $f -replace "/","\"
  $dir = Split-Path $out
  if ($dir) { New-Item -ItemType Directory -Force -Path $dir | Out-Null }
  Invoke-WebRequest -Uri $url -OutFile $out
  Write-Host "✅ $f"
}

⚠️ זה לא יעבוד כי האתר דורש התחברות. ראה שלב חלופי למטה ↓

✅ שלב 4 חלופי — השתמש בקבצים שנוצרו כאן

כל הקבצים כבר נמצאים ב-Genspark ותקינים.
פשוט לחץ "Download" על כל קובץ בממשק Genspark (לשונית Files בצד שמאל) ושמור אותו.

📁 צור מבנה תיקיות:
easyfinance-deploy/
easyfinance-deploy/admin/
easyfinance-deploy/css/

שלב 5 — פרסם ל-Cloudflare Pages

wrangler pages deploy easyfinance-deploy --project-name=easyfinance-dashboard

✅ זה מפרסם את הקבצים ישירות ללא D1 ולא נכשל!

🔑 API_BASE בכל הקבצים

כל הקבצים שהורדת כבר מכילים:

const API_BASE='https://usekmdat.gensparkspace.com';

✅ הנתונים יגיעו תמיד מ-Genspark — ללא תלות ב-Cloudflare D1
